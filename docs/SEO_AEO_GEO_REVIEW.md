# مراجعة وتحسين الظهور: rocks-ev.com

تاريخ المراجعة: 12 أكتوبر 2026. التحليل والتنفيذ على المشروع المحلي؛ تعذر الوصول إلى الدومين من أداة البحث والاتصال المباشر بسبب مهلة اتصال. هذا لا يثبت أن الموقع متوقف عند جميع المستخدمين. لا توجد صلاحية لحساب Search Console أو الاستضافة هنا، لذلك لم يتم نشر التغييرات أو التحقق من فهرسة النسخة الحية.

المشروع كان يحتوي بالفعل على عناوين ووصف للمنتجات والأقسام، وcanonical، وفهرسة محدودة للفلاتر، وخريطة موقع، ومحتوى عربي مخزن في قاعدة البيانات. جرى البناء على ذلك دون تغيير slugs المنتجات أو إضافة كلمات مخفية أو مراجعات مصطنعة.

## البيانات التي تحتاج استكمالًا

فحص قاعدة البيانات المحلية وجد 8 أقسام نشطة و12 منتجًا عامًا، وحقول الأسماء والأوصاف العربية موجودة. المنتجات المحلية مطابقة لبيانات `seed_store` التجريبية؛ يجب مقارنة هذا بالكتالوج الفعلي على الاستضافة. الصور الرئيسية فارغة للمنتجات الـ12، وحقول الهاتف والبريد والعنوان باللغتين والحسابات الاجتماعية فارغة. لا يعني ذلك أنها فارغة في قاعدة بيانات الإنتاج.

استكمل المعلومات الحقيقية من لوحة الإدارة؛ لا تستخدم أسعارًا أو مواصفات أو شهادات جودة أو مدد ضمان افتراضية. لكل منتج أضف صورًا أصلية ومواصفات مثبتة مثل طول الكابل وعدد المخارج ونوع الموصل والتصنيف الكهربائي الذي يعلنه المصنع، حيث تنطبق. أدخل نص الضمان الفعلي وشروطه. قوِّ وصف كل قسم بما يخص منتجاته الفعلية، بدل تكرار وصف عام.

يمكن إعادة الفحص دون تغيير البيانات:

```bash
python manage.py audit_seo
python manage.py audit_seo --strict
```

## نشر التعديلات

أضف إلى `.env` الفعلي، مع الاحتفاظ ببقية بياناته الحالية:

```dotenv
SITE_URL=https://rocks-ev.com
ALLOWED_HOSTS=rocks-ev.com,www.rocks-ev.com
CSRF_TRUSTED_ORIGINS=https://rocks-ev.com,https://www.rocks-ev.com
```

إذا كانت الاستضافة تتطلب اسم PythonAnywhere أيضًا، أضفه إلى `ALLOWED_HOSTS` الحالي. تأكد من أن DNS وشهادة HTTPS مربوطان بالدومين المطلوب، واجعل تحويل www إلى الدومين الأساسي في إعدادات الاستضافة متى كان www مفعّلًا.

بعد رفع الملفات إلى الاستضافة:

```bash
python manage.py check
python manage.py test --noinput
python manage.py collectstatic --noinput
python manage.py audit_seo
```

أعد تحميل تطبيق الويب. لا توجد migrations جديدة لهذا التعديل. الإنجليزية على `/`، والعربية على `/ar/`، ودليل الشراء على `/buying-guide/` و`/ar/buying-guide/`. اللغة العامة يحددها الرابط؛ تبديل اللغة ينقل للرابط المقابل ويحفظ الفلاتر، بينما الصفحات الخاصة مثل الدفع تستمر باستخدام كوكيز اللغة.

## خطوات جوجل خارج الكود

1. اثبت ملكية Domain property لـ`rocks-ev.com` في [Google Search Console](https://search.google.com/search-console/about) عبر سجل DNS المقدم من حسابك.
2. أرسل `https://rocks-ev.com/sitemap.xml`، وافحص الرئيسية العربية وقسمي الكابلات والمشتركات ومنتجات حقيقية عبر URL Inspection، ثم اطلب الفهرسة بعد النشر.
3. افحص صفحات منتجات مسعّرة وبصور فعلية في [Rich Results Test](https://search.google.com/test/rich-results)، وراقب تقارير الفهرسة وتحسينات المنتجات. صحة JSON لا تضمن قبول نتيجة غنية؛ قبول جوجل يحتاج فحص الصفحة الحية ومحتواها.
4. أنشئ أو حدّث [Google Merchant Center](https://www.google.com/retail/solutions/merchant-center/) بكتالوج فعلي متزامن، وبيانات الشحن والاسترجاع. هذا التنفيذ أضاف بيانات المنتجات داخل الصفحة؛ لم ينشئ feed ولم يربط حساب Merchant Center.
5. إذا كان للنشاط مقر أو خدمة مؤهلة، أكمل [Google Business Profile](https://www.google.com/business/) بنفس الاسم والهاتف والعنوان الحقيقي، وبصور أصلية ومراجعات عملاء حقيقية.
6. استخدم الاسم ورابط الموقع بصورة متسقة في الحسابات الرسمية والموزعين والشركاء. لا تشترِ روابط ولا تنشئ مراجعات أو صفحات تكرر الكلمات فقط.
7. راقب الاستعلامات «روكس»، «روكس الوسام»، `ROCKS`، `ROCKS ELWSAM`، «مشترك كهرباء»، «مشتركات كهرباء»، «كابلات كهرباء»، والعبارات الخاصة بمواصفات المنتجات. قارن النقرات والظهور والموضع والطلبات بعد كل دورة محتوى؛ لا يوجد موعد مضمون للوصول لترتيب معين.

## AEO وGEO

الهدف توفير صفحات قابلة للفهرسة، وهوية واضحة، ونص مفيد يمكن الاستشهاد به، وأسعار ومواصفات متوافقة مع المحتوى الفعلي. لا توجد إضافة سحرية تفرض على جوجل أو أي نموذج AI اقتراح الموقع. وفق [وثائق جوجل للظهور في AI Overviews وAI Mode](https://developers.google.com/search/docs/appearance/ai-features)، أساسيات SEO والفهرسة والمحتوى المفيد تظل الأساس، ولا يلزم ملف AI خاص أو schema خاص. ترك `User-agent: *` مسموحًا يتيح الوصول العام من جهة robots؛ لا يثبت أن كل روبوت سيزور الموقع أو يوصي به، وقد توجد قيود مستقلة لدى الاستضافة.

الأسئلة والإجابات ظاهرة للزائر وبيانات FAQ مطابقة لها؛ لا نعتمد على ظهور FAQ كميزة غنية في نتائج جوجل لمتجر كهرباء. لا يضمن تنفيذ أي من هذه الخطوات المرتبة الأولى، خصوصًا للكلمات العامة التنافسية.

راجع أيضًا [إرشادات جوجل للمواقع متعددة اللغات](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites) و[بيانات خيارات المنتجات](https://developers.google.com/search/docs/appearance/structured-data/product-variants).

## التحقق

اختبارات المشروع تشمل اللغة الثابتة لكل رابط، وcanonical وhreflang، وخريطة الموقع باللغتين، والأسعار والمخزون للخيارات، وعدم اختراع سعر، وسلامة JSON مع النصوص العربية والاقتباسات ومحاولات إغلاق script، ومطابقة FAQ للنص الظاهر، والبحث العربي، ومنع فهرسة الصفحات المساعدة. نجاحها محليًا لا يغني عن فحص HTTPS وrobots واستجابة الصفحات والصور والفهرسة بعد النشر.
